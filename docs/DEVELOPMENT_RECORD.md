# 人机协作与归档说明

项目由 GitHub 账号维护者负责。人类提供目标、设备与约束，决定停止模型优化，并确认视频暂不制作；Codex助手参与代码整理、排错、有限验证、文档与仓库准备。参赛者负责复核和现场解释代码。

本仓库来源于2026-10-29的参赛源码归档，再增加GitHub首页、部署/架构/测试说明与纯逻辑CI。现有8份核心源码保持字节不变，身份见 `SOURCE_PROVENANCE.json`。Git提交是本次真实整理记录，不冒充此前完整开发历史。

AI精确底层版本、完整聊天导出和逐文件人工/AI贡献比例没有完整记录，因此不虚构版本、比例或节省工时。上游预训练模型归属单独披露。

历史失败和阴性结果按已有回执保留：CPU评分子进程依赖路径修复不等于重新训练或重解码；最终未获得质量收益，模型优化已经停止。GitHub整理不恢复此研究。

仓库不包含私人历史转写、个人纠错词表、SSH密钥、GitHub凭据或模型权重。代码的默认本地路径用于部署说明，不表示已经在新设备重现。
