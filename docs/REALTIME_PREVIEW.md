# 逐步显示与转写保留

说话过程中，页面显示当前句的临时转写；停顿后三路比较给出最终文字，并追加到对话框。
每个临时结果都由已收到的音频实际识别得到，不对整句结果播放逐字动画。

当前预训练识别器是整段识别接口，预览通过重新识别逐渐增长的前缀实现，约每1秒尝试一次。
具体更新速度取决于设备负载；临时字词可以修正，不承诺每个字一发声就固定输出。
最终结果仍用完整分段、raw/GTCRN/FastEnhancer三路和原候选选择逻辑。
临时预览不应用整句纠错记忆，也不保存到转写归档。

预览复用raw识别器并串行保护其调用，不额外加载识别模型。正式处理和语种切换优先；
最多保留一个正在计算和一个最新待算前缀。输入前缀内存上限21秒，起始预留0.5秒已采音频。
可使用`--no-partial-preview`关闭预览。此功能增加推理调用，不能沿用旧吞吐数字描述新版本成本。

## 清空显示

“清空显示”只清除此浏览器的显示，不请求删除后台转写或个性化记忆。
已清除的旧句不会在下一次轮询或刷新时立即回填；新句继续追加。
已确认文字在浏览器本地保留最近500条，刷新后可以恢复；使用共享浏览器时请在结束后清空显示。
后台`transcript_multicandidate.jsonl`继续追加最终记录，和页面清空彼此独立。
服务启动时只读取归档最后512KiB中的最近100条，不重写旧归档。
历史归档不会重新识别音频，也不用于自动训练模型。

“清空本语种记忆”是另外一个按钮，用于删除该语种的纠错记忆；不等同于清空显示。
